# Viability boundary

The safe operating set is $\mathcal{K}=\{x:h_j(x)\ge 0,\ j=1,\ldots,m\}$.

Its controlled invariance condition is

$$
\forall x\in\partial\mathcal{K},\quad \exists u\in\mathcal{U}:\quad \nabla h_j(x)^\top f(x,u)\ge 0.
$$

The already-correct comparison metric is $\Delta R = R_{\mathrm{post}}-R_{\mathrm{pre}}$.
